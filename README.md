# 🏛️ eGov Frontend

A modern frontend application built with **React**, **Vite**, and **TailwindCSS**, designed for e-Government solutions.

---

## ⚙️ Project Setup

frontend/
├── index.html
├── package.json
├── vite.config.js
├── tailwind.config.js
├── postcss.config.js
├── src/ # (components, pages, routes, etc.)
└── node_modules/

---

## 🚀 Features

- ⚡ Fast development with [Vite](https://vitejs.dev/)
- 🌈 Responsive UI using [TailwindCSS](https://tailwindcss.com/)
- 🔁 Client-side routing with `react-router-dom`
- 🧰 Linting setup with ESLint
- 🧼 Tailwind forms support via `@tailwindcss/forms`

---

## 🧰 Tech Stack

- **React 18**
- **Vite** (build tool)
- **TailwindCSS** for styling
- **React Router v7** for navigation
- **ESLint** for linting

---

## 📦 Installation

### 1. Clone the Repository

git clone https://github.com/your-username/egov-frontend.git
cd egov-frontend/frontend
2. Install Dependencies

npm install
3. Start Development Server

npm run dev
Visit the app at http://localhost:5173

📜 Available Scripts

npm run dev       # Start dev server
npm run build     # Create production build
npm run preview   # Preview production build
npm run lint      # Run ESLint
🛠️ Configuration
Vite config: vite.config.js

Tailwind config: tailwind.config.js

PostCSS config: postcss.config.js
